# CreativeGongHak

창의적공학설계(AD) 01분반 실습 저장소입니다.

## 4주차 - 날씨 리포트 개인 프로젝트

Python과 Open-Meteo API를 이용해 사용자가 입력한 지역의 3일간 날씨를 출력합니다.

### 실행

```bash
pip install -r requirements.txt
python API_weather.py
```
